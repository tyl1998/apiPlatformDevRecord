# 问题记录 — 仓库用例树列宽随展开跳动

## 现象

仓库用例树（`/repo-cases`）点开某个接口组的用例行时，整张表格的列宽跳一次；列宽
取决于「当前展开了哪些行」，且截断的内容（用例名、URL、标签）没有悬停提示，看不全。

## 根因

表格用 auto 布局：接口行是 `colSpan=5` 的宽身份格 + 计数格，用例子行是 6 个独立格，
两类行一起参与列宽分配。展开子行后浏览器重新求解列宽，URL 长的接口行与内容宽的
子行互相挤，视觉上整表跳一下。截断单元格（`.truncate`）大多没配 `title`，截断即信息
丢失。

## 修法

- `design-system.css` 新增 `.grid.grid-fixed { table-layout: fixed; }`：树表（主树与
  未归位分组）加 `colgroup` 显式宽度（文件路径 200 / 标签 110-120 / 计数 70 / 时间
  150 / 状态 90，名称列吃剩余空间）。fixed 布局下列宽与展开状态无关，`colSpan` 行与
  子行不再互相挤。
- 截断补悬停：用例名、case_key、文件路径、标签、接口名、接口 URL、详情抽屉里的
  请求路径/参数列全部补 `title`（原生 tooltip，零依赖）。

## 状态

已修（2026-08-30）。`grid-fixed` 是通用工具类，其它有同构问题的表可复用；未全站
替换——auto 布局对纯平铺表仍是合理默认。
