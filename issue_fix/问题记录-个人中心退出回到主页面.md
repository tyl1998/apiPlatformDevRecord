# 个人中心退出回到主页面：口袋页缺回程键

> 2026-09-21 用户报告：从智能助手（抽屉头个人中心钮）进入个人中心后，退出又回到了
> 主页面——期望「从哪里进去，退出就是哪里」。

## 现象

- 在项目页（或任何页面）打开智能助手抽屉 → 点头像旁的「个人中心」→ 落 `/me`。
- 个人中心页**没有任何回程入口**：全局壳顶栏只有数据看板 / 项目管理 / 系统管理三个
  全局导航，`page-head` 里也没有返回钮。离开这里唯一的显式出口就是点顶栏导航——
  于是「退出回到主页面」，进个人中心前正在工作的项目页丢了。
- 浏览器返回虽然可用，但还有两处历史污染会让它不可靠：
  ① 已在 `/me` 时再点抽屉的「个人中心」钮会把同名路由**再压一条**——back 变成
  「回到 /me 自己」；
  ② 页内 tab 切换（`/me` → `/me/mcp`）是 push——back 在 tab 间打转，回不到来源。

## 根因

个人中心是「从任意页进来的口袋页」（助手抽屉、通知深链、项目页都可能是入口），但
P12-2 把它挂到全局层 `/me` 时只做了落点迁移：页面本身不携带来源语义，也没给回程
入口——全局壳的顶栏导航天然只覆盖「全局三页互跳」，`/me` 在其中是异类（从项目层
进来的话，顶栏没有一个键能回去）。抽屉入口 `navigate("/me")` 与页内 tab 导航都按
默认 push 处理，历史栈被当成了导航记录的流水账。

## 修法

1. **`MePage.tsx`：page-head 标题左侧加回程键**（`IconButton` + `ArrowLeft`，文案
   `action.back`「返回」）。行为是 `navigate(-1)`（history back）——从哪进来就回哪，
   不需要自己记来源。`location.key === "default"`（新标签直开 / 刷新后的首条）时
   不渲染：没有上一条可回，顶栏导航就是合理出口。
2. **`MePage.tsx`：tab 切换改 `replace: true`**——tab 是页内 URL 状态（与筛选参数进
   地址栏同款纪律），push 会把「切 tab」记成一次导航，回程键要多按几次。深链与
   「URL 唯一事实源」不受影响。
3. **`AssistantDock.tsx`：已在目标页时不再重复入栈**——抽屉头「个人中心」钮
   （`location.pathname === "/me"` 时只关抽屉不导航）与通知「查看全部」链接
   （`=== "/me/notifications"` 时同款）。否则多压一条同名历史，页面的回程键变成
   「回到 /me 自己」，读作返回键失灵。
4. **`i18n.ts`**：新增 `action.back`（返回 / Back）。
5. **`design-system.css`**：`.me-head`（标题行 + 回程键的 flex 布局；回程键属于标题
   侧，不能直接塞 `page-head` 否则被当右缘操作）。

## 状态

已修（2026-09-21，纯前端、零迁移）。**未经浏览器验证**（仓库约定 Validation
Ownership）：建议路径——① 项目页 → 助手 → 个人中心 → 点标题左侧「返回」→ 应回到
该项目页；② 数据看板进 → 返回 → 回数据看板；③ 在 /me 切几个 tab 再返回 → 仍一步
回到来源；④ 在 /me 再点抽屉「个人中心」钮（应只关抽屉）→ 返回仍一步回来源；
⑤ 新标签直接打开 /me 或刷新 → 不应出现返回钮。
