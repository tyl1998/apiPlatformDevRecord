# 系统管理页标题重复 — 问题记录

日期：2026-08-12

## 需求

全局页面（数据看板 / 项目管理 / 系统管理）里，顶部栏和正文页头都显示当前页面名，用户反馈「系统管理」出现两次，看起来重复且奇怪。期望同一页面名只出现一次。

## 涉及文件

| 文件 | 改动内容 |
|---|---|
| `apitest-web/src/components/GlobalApp.tsx` | 顶部栏、系统管理页正文页头（最终方案：保留顶部栏标题，移除正文 `h1`） |

---

## 问题：顶部栏与正文页头标题重复

**现象**：进入系统管理页时，顶部栏显示 `系统管理`，正文 `page-head` 又显示大号 `系统管理` + 说明文案，同一页面名出现两次。

**原因**：全局页面结构是 `topbar（crumb 标题） + content（page-head h1）` 两层各自渲染当前页面名。对只有少数几个页面的全局区域，顶部栏的页面名和正文标题承担了相同职责。

---

## 尝试过的方案（按顺序）

| 方案 | 改动 | 结果 |
|---|---|---|
| A. 清空顶部栏 | `<header className="topbar" aria-label="..."/>` | 用户认为「更奇怪」——顶部变成一条空白条，被要求回退 |
| B. 顶部栏改面包屑 | `全局 / 系统管理` | 用户认为不行，被要求回退 |
| C. 顶部栏只显示区域 | 顶部 `全局`，正文保留 `系统管理` | 用户要求回退，仍然不接受 |
| D. **移除正文标题（最终）** | 顶部保留 `系统管理`，正文 `page-head` 删除 `h1`，只留说明文案 | 已实施，待用户手动验收 |

### 最终改动

```tsx
// 顶部栏保持原样（页面名）
<header className="topbar"><div className="crumb"><strong>{nav.find(([key]) => key === page)?.[1]}</strong></div></header>

// 系统管理页正文：删除 h1「系统管理」，只留 hint
<div className="page-head"><div><p>{t("system.hint")}</p></div></div>
```

---

## 经验总结

1. **先确认方向再动手**：本轮前两次改动（清空顶部栏、加面包屑）都违背了用户直觉，来回回退。用户的诉求核心是「同一个词不要出现两次」，去掉其中一个比改成别的词更符合直觉。
2. **不要一次性大改布局**：改动标题结构时保留 `topbar` 高度与 `page-head` 布局不变，只删最小元素，便于快速回退和验收。
3. **当前待办**：方案 D 已在 `http://localhost:5174/` 启动，等待用户刷新页面确认视觉效果；若仍有异常，优先在保留顶部栏标题的前提下微调正文页头间距。
