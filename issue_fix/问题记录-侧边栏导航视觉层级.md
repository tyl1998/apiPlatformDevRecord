# 侧边栏导航视觉层级

用户走查项目侧边栏时反馈的四点 UI/UX 视觉问题（分组层级、菜单图标、
选中/Hover 反馈、顶部信息区隔离），一次修复。均为 `apitest-web` 前端样式改动，
无后端与数据变更。

## 1. 分组标题与菜单项层级模糊

- **现象**：「接口资产」「编排与回归」等分组之间完全贴在一起（仅 1px flex 缝隙），
  整列导航难以按板块扫视；组内标题与子项的间距倒是正常。
- **根因**：一条死规则。`.nav-section:first-child { margin-top: 0 }` 本意是消掉
  nav 里第一个分组标题的上边距，但 JSX 里每个分组各自包在一个
  `display: contents` 的 div 里——**每个标题都是自己包裹层的第一个子元素**，
  于是四条标题的上边距全被清零。`.nav-section` 的 margin-top（14px，先后改过
  20px / 28px）从未渲染过，两轮「调大」均无可见效果。
- **修法**：分组从 `display: contents` 透明包裹改为真实的 `.nav-group` 容器
  （flex column + gap 1px），组间距放在组边界上——`.nav-group + .nav-group
  { margin-top: var(--s3) }`（12px，用户三轮目测后定的值：24px 觉得太远）；
  `.nav-section` 只保留下边距 4px（组内标题贴自己的子项），删除失效的
  `:first-child` 规则。940px 顶栏模式下 `.nav-group` 回到 `display: contents`，
  菜单照旧平铺换行（contents 元素不渲染 margin，组间距自动消失）。
- **状态**：已修复。

## 2. 菜单项无图标

- **现象**：所有导航项纯文字，侧栏平淡，逐字读标签才能定位功能。
- **根因**：导航从初版起就是纯文本项。
- **修法**：为每个目的地配一枚 lucide 线框图标（14px，与「返回主页」的箭头同档）：
  接口管理 `Plug`、环境管理 `Globe`、数据源 `Database`、Mock `MessageSquare`、
  流程编排 `Workflow`、测试套件 `Layers`、仓库用例 `FolderGit2`、CI 任务 `Rocket`、
  执行记录 `History`、报告列表 `ScrollText`、趋势分析 `TrendingUp`、告警通知 `Bell`；
  全局侧栏：数据看板 `LayoutDashboard`、项目管理 `Folder`、系统管理 `Settings`。
  图标色 `--ink-3`（比文字退一档，线框不与标签抢重），激活项随文字用 `--accent`。
  `ProjectShell`、`GlobalApp`、`theme-preview`（样式参考页）三处同步。
- **状态**：已修复。

## 3. 选中态与 Hover 反馈弱

- **现象**：选中项只有浅蓝圆角背景，读不出左侧指示条；未选中项悬浮时几乎
  感觉不到反馈。
- **根因**：两处独立成因——① 选中左边条是 `box-shadow: inset 3px 0 0`，阴影
  必须跟随 4px 圆角，上下端被圆角吃掉，读起来只是背景的一截残边；② hover 底色
  `--raised`（浅色 #fbfbfa）画在 `--surface`（#ffffff）上只差约 1.5%，肉眼不可辨。
- **修法**：① 选中改 `::before` 指示条（3px 宽、上下各让 3px、独立 2px 圆角，
  不再跟随按钮圆角）；940px 顶栏模式维持下划线标记并隐藏左条；② 调色板新增
  `--hover` token（浅色 `#f0f0ee` / 深色 `#262b33`，与既有灰阶同族、中性不带色相），
  `theme.ts` 的 `PALETTE` + `CSS_VAR` 与 `design-system.css` 的 `[data-theme]`
  预注水回退两处同步写入，导航 hover 换用它。「返回主页」按钮共享 `.nav-item`，
  一并获得 hover 底色。
- **状态**：已修复。

## 4. 顶部项目信息区与导航未隔离

- **现象**：项目标识（lockup）与「返回主页」和下方导航列表紧挨，没有板块边界。
- **根因**：lockup 与 `nav` 是 `.sidebar` 的平级子元素，只靠容器 gap 分开；
  「返回主页」又混在 nav 首位，头部区域没有归属。
- **修法**：新增 `.sidebar-head`（lockup + 返回主页，`border-bottom: 1px solid
  var(--line)` 分割线 + `padding-bottom: var(--s4)`），`nav` 内只剩纯分组结构；
  940px 顶栏模式下头部折叠为行内组并去掉分割线（横向条里竖线只会把栏切断）；
  `GlobalApp` 的 lockup 同样入 head，两个 shell 一致。
- **状态**：已修复。

## 涉及文件

- `apitest-web/src/design-system.css`：`--hover` token 回退值、`.sidebar-head`、
  `.nav-section` 间距、`.nav-item` flex + svg 着色、`.is-active::before` 指示条、
  940px 媒体查询适配。
- `apitest-web/src/theme.ts`：`PALETTE` 双模式各 +1 `hover` 键、`CSS_VAR` 映射。
- `apitest-web/src/components/ProjectShell.tsx`：`NAV_ICONS` 映射、sidebar-head 结构。
- `apitest-web/src/components/GlobalApp.tsx`：全局导航图标、lockup 入 head。
- `apitest-web/src/theme-preview.tsx`：样式参考页侧栏样本同步新结构。
