# 统计页图表轴刻度叠字（横轴首桶标签压住 y 轴刻度）

> 2026-09-20 用户报告：P10-8 改造后，数据统计页图表的「横轴数据挡到了竖轴的标题」；
> 同日第二轮走查追加三项（刻度栏占宽过大 / 空档要虚线 / x 轴刻度太疏）。
> 涉及 `components/charts/`（P8-5 底座）。开发内容见 `DEVELOPMENT_PLAN_P6-P14.md`
> 14.6，缺陷记本文件。

## 现象

数据统计页（数据看板同款底座）的折线图左下角，横轴首桶的时间标签（`09-20` 这类）
与 y 轴刻度（`0%` / `0ms`）叠在同一带里，刻度被压住。

## 根因

图表底座从 P8-5 起就带着一处布局缺口，P10-8 的卡片化把它变成显眼问题：

- **y 轴刻度没有自己的列**：刻度是 HTML 绝对定位浮层（`.chart-y { left: 0 }`），直接
  贴在绘图区左缘、和曲线共用同一段横向空间，底座从未给它留留白。
- **横轴首桶标签是居中的**：`left: x(index)/CHART_W` + CSS `translateX(-50%)`，而
  `x(0) = PAD_L = 6`（720 宽 viewBox 的 0.83%），所以首桶标签的左半截（约一个标签宽）
  正好落在 y 轴刻度那一列上；尾桶标签同款向右探出面板。
- 两者都贴着图表下缘（y=0 刻度在 `y(0)-7`，横轴标签 `bottom: 0`），于是在左下角叠字。
- P10-8 把统计页正文从「整页滚动」收进 `.list-scroll` 卡片（`.content` 内距外又多一层
  卡边框 + 卡内距，绘图区宽度收窄约 50px），这处叠字从临界变得可见——图表组件本身
  P10-8 未改。

## 修法

**① 刻度栏在绘图区之外，且是固定像素。** 第一版把 left 留白做成 viewBox 内的
`PAD_L = 40`——用户在下一轮走查里指出「两边空白过大」：viewBox 单位是**比例**，宽屏上
40/720 ≈ 5.6% 会吃掉一大片（1400px 的卡宽下刻度栏 78px），而刻度字号是固定 10px，两者
根本不匹配。改为：

- `.chart` 定义 `--chart-axis-gutter: 36px`；`.chart-plot`（新增）`margin-left` 用掉它，
  绘图区 `PAD_L` 回到 6。
- y 轴刻度 `right: 100%; width: var(--chart-axis-gutter); text-align: right`——整枚刻度
  落在绘图区**外面**的刻度栏里、右对齐贴住绘图区左缘，网格线也不再从刻度下面穿过。
- 折线图与柱图共用同一个刻度栏宽度，统计页里上下两图的绘图区左缘保持对齐。

**② 首/尾横轴标签向图内对齐**（`translateX(0)` / `translateX(-100%)`，中间桶仍居中）：
首桶不再回头压刻度栏，尾桶不再探出面板右缘（顺带掐掉卡内横向溢出）；只有一个桶时
维持居中。

**③ x 轴刻度从首/中/尾三个加到最多 6 个**（`axisIndices(n, max)`，首尾必含、去重；
桶数不足 6 时全标）。同时把绘图区左缘固定了，刻度变密也不会挤到 y 轴。

**④ 空桶用虚线连**（`gapSegments`）：null 桶没有数值可画，但两侧**最近的实样本**之间
补一条虚线（一段连续 null 只出一条），线型自己说明「这段是推断」；实样本之间的相邻
连线仍是实线，读数条的「—」仍表达「没样本」。`LineChart` 的 `bridgeGaps` 开关随之
删除（通过率图原先直接断线、耗时分位图原先跨桶连实线——现在两者统一为「实线画样本 +
虚线画推断」），`Trends.tsx` / `GlobalApp.tsx` 两处调用同步去掉该 prop。孤立点仍用
`isolatedIndices` 的 circle 兜底。

**⑤ hover 反查改按指针在绘图区 rect 内的 `clientX - rect.left` 比例**
（`nearestBucket`）：原写法用 `offsetX / 容器宽`，绘图区一旦带留白，参照物（`offsetX`
对 SVG 子元素各浏览器不一致）与分母都会把吸附点整体带偏——「指 A 选 B」是 P8-5 修过的
缺陷，不能退回去。
