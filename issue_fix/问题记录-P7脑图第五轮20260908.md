# 问题记录 — P7 文本用例库脑图（2026-09-08 第五轮验收反馈，三项 + 同日追加一项）

> 范围：三项同源——都出在「节点几何」上：列距与节点宽失配（①②的直接
> 病灶）、行数估算低估（①的放大器）、编辑框宽度/高度双限制（③）。

## ① 脑图节点数据出现「折叠」（内容被盖住）

- **现象**：节点内容展示不全，读作数据被折叠/盖住。
- **根因**（两因叠加）：
  1. **列距失配**：节点 max-width 已是 300px，而列距 PITCH 仍是 280——
     宽节点越进下一列 20px，右列节点左缘被左列节点盖住；
  2. **行数估算低估**：`estimateLines` 按「16 字/行」平估（不分 CJK/ASCII、
     不扣 padding）——case 节点 13px 字号 + 11px padding 的实际容量 ≈15.5
     字/行，32 字标题估 2 行实际 3 行；节点 DOM（height:auto）比布局预留
     （minHeight）高出 19.5px+，文字压到下邻节点上。
- **修法**：PITCH 280→360（300px 节点宽 + ≥60px 连线通道）；估算改按**显示
  宽度加权**（CJK 记 1、ASCII 记 0.6——高估行数只是多留白，低估才会重叠），
  每行容量按实际内容宽算（case 20 字、pre/step/exp 22 字）；高度常数与 CSS
  几何严格对齐（边框 2 + padding 8 + 徽记行 20 + 行距 3 = 33，+2 呼吸）。
- **状态**：已修复（2026-09-08，待复测）。

## ② ⊕ 号挡住了下面的数据

- **现象**：折叠开关小圆盖住节点内容/相邻节点。
- **根因**：multiline 态的 toggle 钉在 `top:5px; right:-7px`——骑在徽记行
  右端，盖住标签 chip/优先级徽章；叠加 ① 的 20px 列重叠，+ 号直接压在右列
  节点文字上。flex 态（root/dir）的旧定位（margin 负值探出 4px）也贴边。
- **修法**：统一改为**绝对定位到节点右缘外的竖直中线**（`top:50% +
  translateY(-50%); right:-20px`，XMind 本体的位置），锚点 `.mindmap-node`
  （补 `position:relative`；`.mindmap-block` 的 relative 移除）。完全离开
  节点边框、落在列间通道里（≥60px），不可能压任何内容；点击路由不变。
- **状态**：已修复（2026-09-08，待复测）。

## ③ 编辑时框内数据仍展示不全，「限制很大」

- **现象**：就地编辑长内容，输入框又窄又矮，看不到自己输入的全部。
- **根因**：双重限制——宽度：编辑沿用节点 max-width（224→300px）；高度：
  第四轮的 textarea `rows` 用同一套会低估的行数估算，`overflow:hidden`
  把超出的草稿裁掉。
- **修法**：编辑节点放宽到 **360px**（`is-editing` 专用宽度，与列距同宽、
  不越进子级列）；textarea **自动量高**——`useLayoutEffect` 在草稿每次
  变化后把高度钉到 `scrollHeight`（绘制前跑、精确、不依赖估算），`rows`
  只作初值；内容族编辑走 `.mindmap-edit.is-block`（徽记独占首行、输入框
  整行全宽）。Shift+Enter 换行、Enter/Tab 提交、Esc 取消、IME 守卫不变。
- **状态**：已修复（2026-09-08，待复测）。

## ④（同日追加）双击存量用例编辑，光标没有默认落在末尾

- **现象**：双击已有的用例/步骤进入就地编辑，文本被**全选**，要再按一次
  方向键光标才落到尾部——想接着写必须先按键。
- **根因**：`MindEditInput` 挂载时一律 `focus() + select()`（全选）——这是
  为**新建占位**设计的（打字即覆盖「新用例」），双击**存量内容**沿用了同
  一策略；而存量编辑的常见意图是**追加**，全选反而挡路。
- **修法**：选区策略按入口区分——edit state 增加 `selectAll` 位：新建
  占位（Tab/Enter 建的用例/目录/前置/步骤/预期）`selectAll: true`（打字
  即覆盖占位文本）；双击存量（`startEdit`）不设——挂载聚焦后
  `setSelectionRange(end, end)` 把光标钉到**末尾**（未测量态的逐帧重试
  里同步落位）。位随 nodes memo 进节点 data，`sameMindNode` 判等同步。
- **状态**：已修复（2026-09-08，待复测）。
