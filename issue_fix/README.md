## 约定

- 新增缺陷一律记录到本目录，**不写入 `DEVELOPMENT_PLAN.md`**。
- 文件命名：阶段/主题清晰即可（`P*-*_ISSUE_LOG.md` 或 `问题记录-*.md`）。
- 每条记录至少包含：现象、根因、修法、状态。
